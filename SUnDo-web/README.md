# 내 루틴

myroutine 앱의 기능을 참고해 만든 개인용 루틴 앱입니다. 서버와 로그인 없이 브라우저에서 동작하고, 데이터는 기기 안(localStorage)에만 저장됩니다.

## 실행
- 폴더에서 `python -m http.server 8765` 실행 후 `http://localhost:8765/index.html` 접속
- 갤럭시폰: Chrome에서 주소 접속 후 메뉴의 "홈 화면에 추가"로 설치 (HTTPS 호스팅 필요, 예: Vercel/GitHub Pages)

## 기능
- 주간 신호등(0〜19% 빨강, 20〜59% 노랑, 60% 이상 초록), 이모지 체크, 연속 일수
- 반복: 매일, 요일 지정, 주 N회, N일마다, 매월 특정 날짜 / 상황 기반 습관 / 쉬는 날(스트릭 유지)
- 난이도 Mini/Plus/Max, 대체 이름, 타이머, 수치 기록, 알람
- 루틴 모드 10개 (홈 상단에서 바로 전환), 습관 순서 편집, 필터
- 투두(미완료 자동 이월), 회고(기분, 좋았던 일, 한마디, 짧은/긴 메모, 형광펜)
- 통계(최근 7일, 30일, 이번 주, 이번 달), 무드 캘린더, 배지
- 위젯용 화면 `index.html?widget=1`, 앱 아이콘 길게 누르기 바로가기
- 다크 모드, 백업 내보내기/불러오기, 태블릿과 폴드까지 넓은 화면 대응
- 프리미엄 기능은 모두 제한 없이 열려 있음. 소셜과 결제는 없음
