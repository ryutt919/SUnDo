# 내 루틴 (SUnDo)

myroutine 앱의 기능을 참고해 만든 갤럭시/안드로이드용 개인 루틴 앱입니다. Flutter로 만들었고, 서버와 로그인 없이 기기 안에만 데이터를 저장합니다. 홈 화면 위젯으로 앱을 열지 않고 체크할 수 있습니다.

## 기능
- 주간 신호등(0〜19% 빨강, 20〜59% 노랑, 60% 이상 초록), 이모지 체크, 연속 일수, 레벨과 배지
- 반복: 매일, 요일 지정, 주 N회, N일마다, 매월 특정 날짜 / 상황 기반 습관 / 쉬는 날과 기간 쉬기(스트릭 유지)
- 난이도 Mini/Plus/Max, 대체 이름, 타이머, 수치 기록과 그래프, 사진 인증, 알람(알림), 습관 복제, 종료, 보관
- 루틴 모드 10개(홈 상단에서 바로 전환), 드래그 순서 편집, 필터, 추천 템플릿
- 투두(미완료 자동 이월), 회고(기분, 좋았던 일, 한마디, 주차 회고, 짧은/긴 메모, 형광펜)
- 주간/월간/연간 계획(체크리스트와 진행률)
- 통계(최근 7일, 30일, 이번 주, 이번 달), 무드 캘린더
- 홈 화면 위젯 3종: 오늘의 루틴(체크 가능), 주간 신호등, 월간 신호등
- 웹앱 백업(JSON) 불러오기, 백업 내보내기, 다크 모드, 폴드/태블릿 넓은 화면 대응
- 프리미엄 기능은 모두 제한 없이 열려 있음. 소셜과 결제는 없음

## 구조 (Flutter 아키텍처 권장안)
```
lib/
  app/        앱 조립(의존성, 위젯/알람 동기화, 위젯 백그라운드 콜백)
  data/       services(저장소, 알림, 위젯, 사진, 백업), repositories
  domain/     models, use_cases(반복 계산, 신호등, 통계, 위젯 데이터, 알람 계획)
  ui/         core(테마, 공용 위젯), features/<기능>/{view_models,views}
android/      네이티브 위젯(Kotlin): TodayWidgetProvider, WeekWidgetProvider
test/         도메인, 저장소, ViewModel 단위 테스트
SUnDo-web/    이전에 만든 웹 버전(참고용)
```

## 실행과 빌드
```
flutter pub get
flutter test
flutter run                       # 연결된 갤럭시폰(USB 디버깅) 또는 에뮬레이터
flutter build apk --release       # build/app/outputs/flutter-apk/app-release.apk
```
APK를 폰으로 옮겨 설치할 때는 "출처를 알 수 없는 앱 설치"를 허용해야 합니다.

## 위젯 추가
- 설정 탭의 "홈 화면 위젯 추가"에서 바로 추가하거나, 홈 화면 빈 곳을 길게 눌러 위젯 목록에서 "내 루틴"을 고릅니다.
- 오늘의 루틴 위젯의 이모지 칸을 누르면 앱을 열지 않고 체크됩니다.
