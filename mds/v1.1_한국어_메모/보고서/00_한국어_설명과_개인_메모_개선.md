## 원인과 조치
- 영어 설명: v1 템플릿이 수집된 원문 description을 그대로 표시했다.
  - 조치: 원문을 읽고 스킬별 한국어 설명 1,120개를 직접 요약했다. 원문은 JSON의 originalDescription에 보존하고 화면에는 한국어만 표시한다.
  - 구체성이 부족하거나 오해할 수 있는 설명은 설치된 SKILL.md 본문을 추가 확인했다.
  - 예: karpathy-guidelines는 “가정을 드러내고 최소한의 변경과 검증으로 AI 코딩 실수 감소”, ml-pipeline-workflow는 “데이터 준비부터 모델 배포까지 머신러닝 전 과정을 연결”.
  - 이름은 호출 식별자여서 번역하지 않는다. 원문 자체에 구체 절차가 없는 항목은 그 한계를 정직하게 표시한다.
- 순서 불일치: 배지 생성에 사용한 Set이 설치 경로 발견 순서를 유지했다.
  - 조치: 데이터와 화면 양쪽에서 도구 이름을 알파벳순으로 정렬한다.
- 개인 메모 부재: 기존 버전에는 스킬별 사용자의 설명을 저장하는 기능이 없었다.
  - 조치: 스킬 이름을 키로 사용하는 별도 메모 저장소와 편집 화면, 목록 미리보기, 검색, 모아보기와 백업을 추가했다.

## 메모 사용법
- 스킬 이름 또는 메모 남기기를 누르고 내 메모에 입력한다.
- 입력 시 자동 저장되며 메모 저장 버튼으로도 저장할 수 있다.
- 상세창을 닫으면 목록의 설명 아래에서 메모를 확인한다. 긴 메모는 목록에서 3줄까지 보이고 상세창에서 전체를 확인한다.
- 메모 있는 스킬 메뉴로 모아보고, 일반 검색에서 메모 내용도 찾을 수 있다.
- 메모 지우기는 현재 스킬의 저장 내용을 삭제한다.
- 메모 백업은 전체 메모를 JSON 파일로 저장하고 메모 불러오기는 백업 내용을 추가한다.
  - 같은 이름에 서로 다른 내용이 있으면 **현재 메모를 보존**하고 충돌 수를 알린다.
- 메모는 이 HTML을 연 브라우저의 localStorage에 저장한다. 다른 브라우저나 다른 파일 경로에서 열면 메모 백업과 불러오기로 옮긴다.
- 브라우저 저장소 읽기나 쓰기 실패는 사용자에게 알린다. 읽기에 실패한 기존 저장값을 덮어쓰지 않는다.
- 메모는 4,000자까지 입력한다. 화면 삽입에 textContent를 사용하여 입력한 HTML을 실행하지 않는다.
- 개인 메모는 생성 HTML이나 저장소 커밋에 자동으로 포함되지 않는다.
