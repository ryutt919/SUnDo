- **사용자 요구사항**: gpt-6.1-sol medium 서브에이전트들로 캘린더 시간 연동 개선을 구현하고, 부모 검토 후 릴리스까지 완료한다.
- **버전**: v1.4.1 (폴더 v1.4.1_캘린더_시간_연동_개선, 앱 1.4.1+8)

## 개요
- 직전 앱: 1.4.0+7, Git 태그 `v1.4.0`, 기존 APK 배포와 동일 서명을 유지한다.
- 이번 버전: 신규 시간 일정과 기존 연결 보정, 날짜/시간 충돌 처리, 동기화 결과 안내를 함께 개선한다.

## 직전 버전과 달라진 점
- 시간 내보내기 없음 → 생성과 수정, 종일 전환 지원.
- 기존 연결 무조건 종일 → 이벤트 ID를 유지한 시간 보정.
- 외부 일정 날짜와 시간 편집 미전송 → 쓰기 가능한 외부 일정도 편집 허용, 원래 길이 유지.
- 무조건 성공 안내 → 성공, 부분 실패, 권한 부족, 연동 꺼짐과 실패 구분.

## 방법론
- gpt-6.1-sol medium 에이전트 3개가 데이터, UI, 릴리스 조사와 네이티브 테스트를 분담한다.
- gpt-6 부모가 Journal 필드 patch와 삭제 경합 보호, 통합 검토, 환경 검증과 릴리스를 담당한다.
- 신규 시간 일정 기본 길이는 60분으로 적용하며 외부 일정의 길이와 메타데이터는 유지한다.
- 날짜와 시간을 묶어서 마지막 성공값과 비교하고 동시 변경은 앱 우선으로 처리한다.

## 검증과 재현성
- 코드 검토 후 양쪽 Flutter 분석과 전체 테스트, Android 실제 캘린더 통합 테스트를 수행한다.

- 커밋, 테스트 수, 빌드와 서명, CI 실행 및 APK 해시는 보고서에 기록한다.

## 영향과 해석 주의
- 가져온 쓰기 가능 일정의 날짜와 시간 변경도 원본 캘린더에 적용된다.
- 읽기 전용 일정은 외부에 쓰지 않고 편집 제약과 동기화 결과로 안내한다.
- 레거시 연결의 양쪽 일정이 다르게 바뀐 경우 자동 추정으로 덮지 않고 충돌을 안내한다.
