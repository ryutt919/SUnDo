## Component Status

### 앱 본체
- **Current value/logic**: 순수 HTML/CSS/JS PWA, 빌드 없음. 상태는 localStorage 키 `myroutine.v1`
- **Implementation**: [app.js](../SUnDo-web/js/app.js) 단일 파일(상태, 도메인 로직, 렌더, 이벤트), [style.css](../SUnDo-web/css/style.css), [index.html](../SUnDo-web/index.html)
- **Rationale**: 서버 없이 갤럭시폰 Chrome 설치형으로 쓰기 위해. 원본 조사 보고서 기준으로 기능 재구현, 원본 코드와 자산은 사용하지 않음

### 신호등 규칙
- **Current value/logic**: 달성률 60% 이상 초록, 20% 이상 노랑, 그 미만 빨강, 쉬는 날은 파랑. 오늘 0%는 진행 중으로 보고 색을 칠하지 않음
- **Rationale**: 임계값은 스토어 조사 자료(gogumafarm 기사) 기준

### 위젯
- **Current value/logic**: `index.html?widget=1` 화면과 manifest shortcuts. 진짜 홈 화면 위젯은 아님
- **Rationale**: PWA는 안드로이드 홈 화면 위젯을 만들 수 없음. 진짜 위젯은 네이티브 앱(Kotlin 또는 Capacitor)이 필요

### 미확인 영역 (원본 추정)
- 원본의 로그인 뒤 화면(추가 폼, 통계 화면 등)은 조사하지 못해 직접 설계함
- 형광펜, 목표 탭, 레벨 산식은 원본 의미를 확인하지 못해 형광펜은 메모 강조로 구현, 목표 탭은 미구현
