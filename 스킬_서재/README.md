# 스킬 서재

설치된 스킬을 한국어 설명으로 찾아보고 개인 메모를 남기는 독립 HTML 도구입니다.

**[현재 스킬 서재 열기](htmls/v1.1_한국어_메모/01_설치된_스킬.html)**

- 1,120개 스킬의 짧은 한국어 설명, 분야와 설치 도구 필터를 제공합니다.
- 스킬을 클릭하면 메모를 작성할 수 있고 입력한 내용은 브라우저에 저장됩니다.
- 설치 도구는 Claude Code / Codex 알파벳순으로 표시합니다.
- 메모 백업과 메모 불러오기로 파일에 보관하거나 다른 브라우저로 옮길 수 있습니다.

## 실행과 갱신

완성 HTML은 파일을 더블클릭해서 엽니다. 서버나 별도 설치가 필요하지 않습니다.

다음 명령은 이 README가 있는 스킬_서재 폴더에서 실행합니다.

```powershell
python scripts/04_build_localized_atlas.py --collect-only
python scripts/04_build_localized_atlas.py
node scripts/05_verify_localized_atlas.mjs
```

- 새 이름이 수집되면 data/v1.1_한국어_메모의 한국어 설명 대응표에 설명을 먼저 추가해야 합니다. 설명이 빠진 상태로 빌드하면 오류를 알립니다.
- 기존 버전의 결과를 보관해야 할 때는 새로운 버전 경로를 정하고 작업합니다.
- 수집과 생성에는 Python 3와 PyYAML, 검증에는 Node 22 이상, Chrome / Edge와 전역 TasteSkill의 CDP 모듈이 필요합니다.

## 경로 이동 후 개인 메모

- 파일 경로가 바뀌면 기존 브라우저 메모가 새 서재에 자동으로 나타나지 않을 수 있습니다.
- 기존 탭에 메모가 있다면 그 탭에서 메모 백업을 누르고, 새 서재에서 메모 불러오기를 사용하세요.
- 브라우저 저장소와 기존 탭을 지우거나 닫는 작업은 하지 않았습니다.
- 파일 정리 과정에서 사용자의 실제 메모를 읽거나 자동으로 이전하지 않았습니다.
